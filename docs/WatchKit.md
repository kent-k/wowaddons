# 표시판 (WatchKit) — 개발 문서

> 상태: 구현 (v0.9.0) · 작성 2026-11-21
> 대상 클라이언트: WoW 포에버 1.60.x (최신 엔진 12.x, 비밀 값 있음)

## 1. 왜

- 마법봉 사격을 단축키에 넣어 두고 안 눌러서 깜빡한다 → 처음엔 편의 모음에 "마법봉 알림"(v0.8.2)을 넣었다.
- 사용자 요청: 마법봉만이 아니라 범용으로, 그리고 **판단해서 경고하는 대신 비주얼로 표시만**.
- WeakAuras 류는 최신 엔진에서 쓸 수 없고 도우미로 배포도 안 된다 → 우리 애드온으로.
- 최신 엔진은 애드온이 전투 값(쿨다운·버프 시간·체력)을 숫자로 판단하는 걸 막지만, 위젯(쿨다운 회전, 글자)에 넘겨 보여 주는 건 허용한다. 표시판은 이 원칙에 맞춘다.

## 2. 화면

두 가지를 각각 켜고 끈다 (사용자 요청: "둘 다, 토글되게").

| 표시 | 켜고 끄기 | 내용 |
|---|---|---|
| 아이콘 줄 | `/표시판 줄`, 설정 창 체크 | 고른 항목을 한 줄로. 밝음 = 켜짐/있음, 어두움(흑백) = 꺼짐/없음, 빨간 테두리 = 깜빡한 것. 쿨다운 회전·버프 남은 시간·아이템 개수·무기 강화 남은 분 |
| 단축바 버튼 반짝 | `/표시판 반짝`, 설정 창 체크, 항목마다 체크 | 깜빡한 항목의 **기존 단축바 버튼**에 노란 테두리 깜빡임 |

- 아이콘 줄 옵션: 전투 중에만 보이기, 크기 -/+, 옮기기(`/표시판 잠금`).

## 3. 항목 종류

| 종류 | 밝음 | 깜빡함(반짝) | 쓰는 API |
|---|---|---|---|
| 기술 | 쓸 수 있음 | 없음 | `C_Spell.IsSpellUsable`, 쿨다운: `C_Spell.GetSpellCooldownDuration` → `SetCooldownFromDurationObject`, 없으면 `GetSpellCooldown` → `SetCooldown`(pcall) |
| 버프 | 내게 있음 | 없음 | `C_UnitAuras.GetAuraDataBySpellName("player", 이름)`, 시간: `C_UnitAuras.GetAuraDuration` 또는 산수(pcall) |
| 자동 반복 (5019 사격, 75 자동 사격, 6603 자동 공격) | 켜져 있음 | 전투 중 + 공격할 수 있는 대상 + 시전 안 함 + 1.5초 놀기 (사격은 마법봉 착용 시) | `START/STOP_AUTOREPEAT_SPELL`, `PLAYER_ENTER/LEAVE_COMBAT` |
| 아이템 | 1개 이상 | 없음 | `C_Item.GetItemCount`, `C_Container.GetItemCooldown` |
| 무기 강화 (주/보조) | 걸려 있음 | 없음 | `GetWeaponEnchantInfo` |

- 추가: 설정 창 위 칸에 주문책·가방·단축바(매크로 포함)에서 끌어다 놓기. 남이 걸어 주는 버프는 이름으로(`/표시판 버프 이름`). 무기만 볼 땐 [주 무기]/[보조 무기].
- [종류] 버튼: 끌어온 기술은 기술 ↔ 버프 (↔ 자동 반복), 아이템은 아이템 → 주 무기 강화 → 보조 무기 강화. 독 아이템을 무기 강화로 두면 그 독 버튼이 반짝인다.
- 단축바 버튼 찾기: `ActionButton`, `MultiBar*Button` 1~12 의 `action` → `GetActionInfo`. 기술은 번호 또는 **이름**으로 맞춘다(등급이 달라도). 매크로는 `GetMacroSpell`/`GetMacroItem`.
- 반짝 프레임은 보호된 단축바 버튼의 자식이라 **전투 밖에서만 만든다**. 전투 중 단축바가 바뀌면 전투가 끝난 뒤 다시 찾는다. 보이기/숨기기는 전투 중에도 된다(보호 안 된 프레임).
- 비밀 값이면 "모름"으로 두고 밝기를 바꾸지 않는다.
- 저장: `WatchKitDB`(공용: 줄/반짝 켜기, 크기, 위치, 잠금), `WatchKitCharDB.list`(캐릭터마다 항목, 최대 16개).
- 첫 접속 기본 항목: 마법사·사제·흑마법사 = 마법봉 사격, 사냥꾼 = 자동 사격.

## 4. 확인할 것 (게임 안)

- `C_Spell.GetSpellCooldownDuration`, `SetCooldownFromDurationObject`, `C_UnitAuras.GetAuraDuration` 이 이 클라이언트에 있는지 (없으면 옛 방식으로 내려감)
- 전투 중 버프 확인이 비밀 값으로 막히는지
- 기본 단축바 버튼 이름이 위 목록과 같은지, 버튼에 `action` 필드가 있는지
- 끌어다 놓기 때 `GetCursorInfo` 의 4번째 값이 주문 번호인지

## 5. 파일

```
addons/WatchKit/
  WatchKit.toc
  WatchKit.lua   항목 판정, 아이콘 줄, 단축바 반짝, 이벤트
  Config.lua     설정 창(끌어다 놓기, 종류, 순서), 명령어
  Bindings.xml   설정 창 단축키
```
- `/마법봉` (v0.9.3): 옛 편의 모음 명령어를 표시판에 다시 붙임. 마법봉 사격 항목이 없으면 넣고(반짝임 꺼져 있으면 켬), 착용 여부·아이콘 줄/반짝 상태를 채팅에 보여 준다.
