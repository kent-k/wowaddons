# 퀘스트 비서 (QuestKit) — 개발 문서

> 상태: 구현 (v0.7.0) · 작성 2026-11-14
> 대상 클라이언트: WoW 포에버 1.60.x (Interface 16001)

## 1. 한 줄 요약

끝낸 퀘스트의 아이템이 가방 칸을 먹지 않게 찾아서 알려 주고 클릭으로 지운다. 덤으로 툴팁 진행도, 목표 완료 알림, 퀘스트 목록 레벨 표시.

## 2. 참고한 기존 애드온

| 애드온 | 가져온 것 | 안 가져온 것 |
|---|---|---|
| Questie / pfQuest / Codex | 몹·아이템 툴팁에 퀘스트 진행도, 퀘스트 목록 [레벨], 목표 완료 알림 | 지도에 퀘스트 위치 표시 — 퀘스트·NPC·몹 위치 데이터베이스(수 MB)가 필요하고 한글 클라이언트용 데이터가 없음 |
| QoLKit (우리 것) | — | 자동 수락/완료는 편의 모음에 이미 있음 → 중복하지 않음 |

## 3. 퀘스트 아이템 정리 (핵심)

가방에서 **퀘스트 분류(12) 아이템**, **퀘스트 시작 아이템**, **진행 중 목표와 이름이 같은 아이템**을 모아 넷으로 나눈다.

| 분류 | 판정 | 지우기 |
|---|---|---|
| 진행 중 | 진행 중 퀘스트 목표 이름과 같음 / 진행 중 퀘스트와 연결됨 / 아직 안 받은 퀘스트를 시작하는 아이템 | 버튼 없음 |
| **지워도 됨** | 연결된 퀘스트를 보고함 (`QUEST_TURNED_IN` 또는 `IsQuestFlaggedCompleted`) / 이미 끝낸 퀘스트를 시작하는 아이템 | 한 번 클릭, 전부 지우기 대상, 가방에 빨간 X |
| 포기한 퀘스트 | 연결된 퀘스트가 보고 없이 목록에서 사라짐 | 한 번 클릭 (다시 받을 수 있어서 전부 지우기에선 뺌) |
| 확인 필요 | 어디에도 안 걸림 (퀘스트 사슬 다음 단계에 쓰일 수 있음) | 두 번 클릭 |

**아이템 ↔ 퀘스트 연결 (배우기, 모든 캐릭터 공용 저장)**
- 목표 문장 `"멧돼지 고기: 3/10"` 의 이름과 가방 아이템 이름이 같으면 연결.
- 퀘스트 수락 전후 2~3초 안에 새로 들어온 퀘스트 아이템은 그 퀘스트와 연결 (목표에 안 나오는 전달용 편지 등).
- 그래서 **설치 전에 받은 퀘스트의 목표 밖 아이템은 '확인 필요'** 로 보인다.

**지우기**: 버튼 클릭(하드웨어 입력) 안에서 `PickupContainerItem` → `DeleteCursorItem`. 지우기 직전에 그 칸의 아이템 번호를 다시 확인한다. 전부 지우기는 한 번에 하나 (아이템 잠김 때문에 한 프레임에 여러 개를 안 지움).

**보고 직후**: 1.5초 뒤 그 퀘스트의 남은 아이템을 채팅에 링크로 알리고 정리 창을 연다 (`/퀘스트 자동창` 으로 끔, 전투 중엔 안 엶).

## 4. 그 밖의 기능 (각각 켜고 끔)

| 명령 | 기능 |
|---|---|
| `/퀘스트 툴팁` | 아이템 툴팁: 분류와 이유 / 목표 아이템 진행도. 몹 툴팁: 처치 목표 진행도 (목표 이름에 몹 이름이 들어 있으면) |
| `/퀘스트 알림` | 목표를 다 채우면 화면 글자 + 소리 + 채팅 |
| `/퀘스트 레벨` | 퀘스트 목록 제목 앞에 `[레벨]` (`QuestLog_Update` 뒤에 고쳐 씀) |
| `/퀘스트 자동창` | 보고 뒤 정리 창 자동 열기 |
| `/퀘스트 표시` | 가방 칸에 빨간 X (`ContainerFrame_Update` 뒤) |

## 5. 클라이언트 API (v0.7.1)

WoW 포에버는 최신 엔진이다 (`GetQuestLogTitle`, `OnTooltipSetItem`, `ContainerFrame_Update` 없음). v0.7.0 은 옛 API 로 짜서 퀘스트 목록을 읽다 오류가 나 가방 스캔까지 멈췄다 ("가방에 퀘스트 아이템이 없습니다").
- 퀘스트: `C_QuestLog.GetInfo` / `GetQuestObjectives` (목표 문장이 `"3/10 이름"` 순서) 우선, 옛 API 는 대체.
- 툴팁: `TooltipDataProcessor.AddTooltipPostCall`. 몹 이름이 비밀 값이면 건너뜀.
- 가방 X 표시: 통합 가방 포함 `frame:EnumerateValidItems()`, `UpdateItems` 뒤에 그림. 재료 가방(5) 포함.
- 퀘스트 목록 [레벨]: 옛 퀘스트 창(`QuestLog_Update`)이 없으면 꺼짐.
- 퀘스트 목록·가방 읽기는 `pcall` 로 감싸 하나가 실패해도 다른 것은 동작하고, 실패 이유를 채팅에 한 번 알린다.

## 6. 한계

- 드랍 몹 정보가 없어서 "이 몹이 목표 아이템을 떨군다" 는 모른다 (처치 목표만 몹 툴팁에 표시).
- 퀘스트 번호를 주지 않는 클라이언트면 연결 배우기가 안 됨 → 목표 이름 일치만 동작.
- 가방 애드온(Bagnon 등)에는 빨간 X 가 안 붙는다 (정리 창은 동작).
