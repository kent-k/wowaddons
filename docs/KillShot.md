# 킬각 (KillShot) — 개발 문서

> 상태: **운영 중지 (v0.7.1)** · 작성 2026-11-12
>
> 게임에서 "KillShot가 지원하는 기능이 차단되었습니다" 창이 떴다. 이 클라이언트는 최신(한밤 계열) 엔진이라
> ① 애드온의 전투 기록(`COMBAT_LOG_EVENT_UNFILTERED`) 등록을 막고 ② 전투 중 대상 체력을 비밀 값(`issecretvalue`)으로 준다.
> 데미지도 체력도 알 수 없으므로 기능을 걷어 내고 안내만 남겼다. 아래는 원래 설계 기록.
> 대상 클라이언트: WoW 포에버 1.60.x (Interface 16001)

## 1. 한 줄 요약

내 대상(적)의 남은 체력보다 **한 방 데미지가 큰 스킬**이 단축바에 있으면 그 버튼을 초록색으로 반짝이게 한다. 도트(지속 피해)는 셈에서 뺀다.

## 2. 데미지를 아는 방법

게임에는 "이 스킬의 데미지" 를 알려 주는 기능이 없다. 두 가지를 쓴다.

| 출처 | 방법 | 표시 |
|---|---|---|
| **실전 기록 (우선)** | 전투 기록(`COMBAT_LOG_EVENT_UNFILTERED`)에서 내가 넣은 **직접 피해**(`SPELL_DAMAGE`, `RANGE_DAMAGE`)만 스킬별로 최근 20번 저장. 치명타·빗맞음(glancing)은 버림. 지속 피해(`SPELL_PERIODIC_DAMAGE`)는 기록하지 않으므로 도트는 자동으로 빠진다 | 버튼 숫자 흰색 |
| **툴팁 추정 (기록 없을 때)** | 숨긴 툴팁으로 주문 설명을 읽어 "X~Y의 ... 피해" 의 X(최솟값). "~초에 걸쳐" 가 먼저 나오면 도트로 보고 뺀다. 주문력은 빠져 있어 실제보다 낮게 나옴 = 안전한 쪽 | 버튼 숫자 회색 |

- **"확정 킬" 값**: 기록이 5번 이상이면 낮은 쪽 20% 지점 값, 그보다 적으면 최솟값. 치명타는 계산에 넣지 않는다.
- 저장 키: 주문 번호(전투 기록이 번호를 주면) + 주문 이름 (클래식 계열은 전투 기록 번호가 0 일 수 있어서). 캐릭터별 저장 (`KillShotCharDB`).
- 자동 사격·마법봉 사격·근접 자동 공격은 제외.

## 3. 대상 체력

- `UnitHealth("target")` / `UnitHealthMax`. 적대적이고 살아 있는 대상만.
- **클래식 계열은 몹 체력을 % (최대 100) 로만 줄 수 있다.** 최대 체력이 100 이고 대상 레벨이 10 이상이면 "% 로만 나옴" 으로 보고 반짝이지 않는다 (`/킬각 검사` 에 표시).

## 4. 단축바

- 블리자드 기본 단축바 5줄: `ActionButton`, `MultiBarBottomLeftButton`, `MultiBarBottomRightButton`, `MultiBarRightButton`, `MultiBarLeftButton` × 12.
- 버튼의 동작 칸 → `GetActionInfo` → 주문 (매크로면 `GetMacroSpell`).
- 마나·기력 부족 등으로 지금 못 쓰는 버튼(`IsUsableAction` 거짓)은 반짝이지 않는다.
- 버튼 위에 초록 테두리 + 깜빡임, 아래에 예상 데미지 숫자 (설정으로 끌 수 있음).
- 0.1초마다 갱신 (대상이 있을 때만).

## 5. 한계

- 빗나감·저항은 알 수 없다 → "한 방에 죽일 만큼 세다" 까지만.
- 연계 점수·분노량에 따라 바뀌는 기술(절개, 흉포한 이빨, 마무리 일격)은 기록이 섞여 부정확 → 2차.
- 다른 단축바 애드온(Bartender 등) 미지원.

## 6. 게임 안 안내

- `/킬각` 켜기/끄기, `/킬각 숫자` 데미지 숫자 표시 켜기/끄기, `/킬각 검사` 결과 창(대상 체력이 실제 숫자인지, 단축바 스킬별 예상 데미지와 출처), `/킬각 초기화` 기록 지우기, `/킬각 도움말`. 별칭 `/ks`.
- 접속 시 한 줄, `.toc` `X-Usage-N`.
