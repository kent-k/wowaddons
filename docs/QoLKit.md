# 편의 모음 (QoLKit) — 개발 문서

> 상태: 구현 (v0.5.0) · 작성 2026-11-10
> 대상 클라이언트: WoW 포에버 1.60.x (Interface 16001)

## 1. 한 줄 요약

클래식 기본 UI 에 없는 작은 편의 기능을 한 애드온에 모았다. 기능마다 켜고 끌 수 있고 (`/편의` 설정 창), 기본은 모두 켜짐.
던전 안 퀘스트 목록은 던전 네비(DungeonNav) 지도 창에 붙인다.

## 2. 기능

| 기능 | 하는 일 | 쓰는 API | 주의 |
|---|---|---|---|
| 빠른 줍기 | 자동 줍기 상태에서 루팅 창이 뜨는 즉시 전부 줍는다 | `LOOT_READY`, `GetNumLootItems`, `LootSlot` | 자동 줍기(게임 설정)가 꺼져 있으면 동작 안 함 → 설정 창에서 켜는 버튼 제공. 줍기 키(Shift)로 뒤집은 경우도 존중 |
| 회색 템 판매 | 상인 창을 열면 가방의 회색(잡동사니) 아이템을 판다 | `MERCHANT_SHOW`, 가방 API, `UseContainerItem` | 한 번에 너무 많이 팔면 서버가 거절 → 0.2초 간격으로 나눠 판다. 판 금액을 채팅에 한 줄 |
| 자동 수리 | 수리 가능한 상인이면 내 돈으로 모두 수리 | `CanMerchantRepair`, `GetRepairAllCost`, `RepairAllItems` | 클래식에는 길드 은행이 없어 길드 수리는 없음. 돈이 모자라면 안내만 |
| 쿨다운 숫자 | 단축바 아이콘 위에 남은 시간을 숫자로 | 게임 설정 `countdownForCooldowns` 이 있으면 그걸 켬. 없으면 쿨다운 프레임 `SetCooldown` 에 걸어서 직접 표시 | 직접 표시는 2초 이상(전역 쿨다운 제외), 아이콘 크기 20px 이상만 |
| 우편 모두 받기 | 우편함에 [모두 받기] 버튼. 돈과 아이템을 차례로 받는다 | `GetInboxHeaderInfo`, `TakeInboxMoney`, `TakeInboxItem` | 대금 청구(착불) 우편은 건너뜀. 가방이 꽉 차면 멈춤. 0.3초 간격 |
| 퀘스트 빠른 진행 | Shift 를 누른 채 NPC 와 대화하면 수락/완료를 자동으로 누른다 | `QUEST_DETAIL`→`AcceptQuest`, `QUEST_PROGRESS`→`CompleteQuest`, `QUEST_COMPLETE`→`GetQuestReward` | 보상을 골라야 하는 퀘스트는 멈춘다 (직접 고르게). 설정에서 "Shift 없이 항상" 선택 가능 |
| 던전 퀘스트 목록 (DungeonNav) | 인던 안에서 지도 창 옆에 그 던전의 퀘스트와 목표 진행도 | 퀘스트 목록의 지역 머리글 = 던전 이름 | 머리글이 접혀 있으면 목표를 못 읽음 → 안내 |

## 3. 설정 창 (`/편의`)

- 와우 기본 틀(`BasicFrameTemplateWithInset`) 360 x 400. 기능마다 체크박스 + 설명 한 줄.
- 빠른 줍기 줄에 "게임의 자동 줍기: 켜짐/꺼짐 [켜기]".
- 퀘스트 줄에 "Shift 누를 때만 / 항상" 선택.
- 저장: `QoLKitDB` (공용 — 모든 캐릭터 같은 설정).

## 4. 게임 안 안내 (저장소 규칙)

- 접속 시 한 줄: 버전 + `/편의`.
- `/편의` 설정 창, `/편의 도움말`, 별칭 `/qol`, `/qolkit`.
- 기능이 실제로 무언가 했을 때만 채팅 한 줄 (예: "회색 아이템 7개 판매: 1실 23동", "수리: 2금 10실").
- `.toc` 의 `X-Usage-N` → 애드온 도우미 [사용법].

## 5. 파일

```
addons/QoLKit/
  QoLKit.toc
  Core.lua        설정 DB, 모듈 등록, 설정 창, 명령어
  Loot.lua        빠른 줍기
  Merchant.lua    회색 템 판매, 자동 수리
  Cooldown.lua    쿨다운 숫자
  Mail.lua        우편 모두 받기
  Quest.lua       퀘스트 빠른 진행
addons/DungeonNav/DungeonNav.lua   던전 퀘스트 목록 패널 추가
```

## 6. 확인할 것 (게임 안)

- 빠른 줍기가 실제로 빨라지는지, 줍기 키로 끈 경우 줍지 않는지
- 회색 판매 금액 표시, 수리 금액 표시
- `countdownForCooldowns` 설정이 이 클라이언트에 있는지 (`/편의 도움말` 에 어느 방식인지 표시)
- 우편 첨부 개수 (클래식은 1개일 수도 있음 — 코드는 개수와 무관하게 동작)
- 퀘스트 목록 머리글이 던전 이름과 같은지 (다르면 던전 퀘스트 목록이 비어 보임)

## 7. 나중에
